# Third-party notices and clean-room boundary

OpenJev is an independent implementation. It does not contain proprietary Jev model
weights, training data, private source code, sampler code, or private implementation
details.

The public design review in `docs/TYPESAFE_10_REPO_REVIEW.md` informed high-level
interface and composition ideas. Public concepts such as typed questions, provider
adapters, structured output, and probability distributions are used as architectural
references only.

No third-party source file is vendored in this repository.
